**# File Automation and Organization Script**



**## 📌 Project Overview**

This project is a Python-based automation script developed to perform file management tasks such as sorting files into folders based on their file types. The script reduces manual effort and helps maintain an organized directory structure.



This project was developed as part of an internship task to demonstrate practical usage of OS-level file handling, exception handling, logging, and user input.



---



**## 🛠️ Features**

\- Automatically sorts files into folders (Images, Documents, Videos, Others)

\- Creates folders dynamically if they do not exist

\- Uses Python `os` and `shutil` modules for file operations

\- Implements exception handling to avoid crashes

\- Generates a log file (`automation.log`) for all operations

\- Accepts user input for directory path



---



**## 📂 Technologies Used**

\- Python 3

\- os module

\- shutil module

\- logging module



(All modules used are part of Python’s standard library)
